# agent-toolkit-for-kapitan (archived)

The Kapitan plugins moved to **[Moep90/agent-skills](https://github.com/Moep90/agent-skills)**,
now versioned per plugin.

```text
/plugin marketplace add Moep90/agent-skills
/plugin install kapitan-core@moep90-skills
```

Codex CLI: `codex plugin marketplace add Moep90/agent-skills`, then
`codex plugin add kapitan-core@moep90-skills`.

The Kapitan MCP server in `tools/kapitan-mcp` was not moved; it stays here for reference.
